## 示例

```markdown
# CC-D001: 动画系统选型 - 使用 XTween

**分类**: cocos-creator
**状态**: ✅ 已采纳
**日期**: 2026-01-10
**来源项目**: ssd_thly
**适用范围**: 所有 Cocos Creator 项目的动画需求

## 背景

项目需要大量 UI 动画（淡入淡出、缩放、位移等），需要选择合适的动画实现方式。

## 考虑的方案

| 方案 | 优势 | 劣势 |
|------|------|------|
| Cocos tween | 官方 API，无学习成本 | 功能有限，无法暂停/恢复 |
| XTween (✅) | 功能丰富，支持暂停/恢复/链式 | 需要学习新 API |
| 动画编辑器 | 可视化，设计师可调 | 代码控制灵活性差 |

## 决策

采用 **XTween**

框架已内置，功能更强大，团队已有使用经验。

## 实现要点

\`\`\`typescript
import { XTween } from 'framework/xtween/XTween';

// 基础用法
XTween.to(node, 0.3, { opacity: 0 }).play();

// 链式动画
XTween.to(node, 0.2, { scale: 1.2 })
  .to(node, 0.2, { scale: 1 })
  .play();
\`\`\`

## 影响

- 所有 tween 动画统一使用 XTween
- CLAUDE.md 添加禁止直接使用 Cocos tween 的规则

## 可复用场景

- 任何需要代码控制动画的 Cocos Creator 项目
- 需要动画暂停/恢复功能的场景
```
